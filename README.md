## 🛠️ Projeto em destaque

### Barra de Skills para Bloodstone

Programa para Windows que copia as skills do jogo Bloodstone para barras personalizáveis na tela, com recarga, nível e contagem dos buffs ativos. Ele só lê a imagem da tela: não mexe na memória do jogo nem envia teclas.

- Reconhecimento de magias e buffs comparando a tela com ícones, sem acessar a memória do jogo.
- Interface em CustomTkinter, com perfis por personagem e executável gerado com PyInstaller.
- Testes automatizados no próprio projeto.

Python · NumPy · Pillow · Tkinter / CustomTkinter · Win32 API (ctypes) · PyInstaller
